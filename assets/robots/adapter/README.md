# i10 → RH56 连接件

当前装配关系以 [文档版合同](../../../doc/assembly_contract.md#当前装配变换) 为主记录；本文保留资产来源、转换依据与使用说明。

2026-09-20 用户提供 [连接件.STEP](source/连接件.STEP) 和 [连接件.STL](source/连接件.STL)，明确为同一连接件的不同坐标描述，并指定替换当前占位件。此资产不采用历史 FR3 转接件。

## 坐标与尺寸

- STEP 声明长度单位为毫米，底面中心为 `(0, 0, 0)`，轴线沿 Z；底部圆盘半径 31.5 mm、高 10 mm，上部外圆半径 19 mm，总高 25 mm。
- STL 包围盒为 `[0, 0, 0]` 至 `[63, 63, 25]` mm。转换采用 `p_adapter = (p_STL - [31.5, 31.5, 0]) × 0.001`，保持轴向不变。
- 派生网格 `meshes/adapter.stl` 单位为米，包围盒为 `[-0.0315, -0.0315, 0]` 至 `[0.0315, 0.0315, 0.025]`，保留 6124 个三角面及孔洞。
- 核对 STEP 的 38 个拓扑顶点到平移后 STL 表面的最大距离约为 0.001652 mm；这支持坐标偏移判断，并非完整 CAD 曲面等价性证明。

## 安装与使用边界

组合预览将底面中心放在传感器输出端面（`sensor_output_frame`，距 `wrist3_Link` 沿 +Z 33.5 mm），+Z 指向手侧；按用户要求将上部凸台全部插入手根部，`rh56_provisional_mount` 从 `(0, 0, 0.025)` 改为 `(0, 0, 0.010)` m，使手根部贴住底盘肩面。插入深度为 `25 - 10 = 15 mm`。旋转仍取单位旋转。这是按肩面就位的静态装配预览，未验证内部几何干涉或真实插装过程；实物安装角度、手基座接口和法兰配合尚未标定。

当前替换显示几何，沿用原预览的无碰撞、零密度设置；质量、惯量及接触模型尚未交付。不能将此显示网格的加载成功视为动力学验证。

重建：

```bash
.venv/bin/python tools/build_adapter_mesh.py
.venv/bin/python tools/build_i10_hand_preview.py
.venv/bin/python tools/view_mjcf.py --with-hand --check
```

原始 STEP/STL 已从根目录归档到 `source/`，保留原名与内容。校验记录见 [SHA256SUMS](source/SHA256SUMS)。
