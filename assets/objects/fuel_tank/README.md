# 油箱粗略模型

入口：[urdf/fuel_tank.urdf](urdf/fuel_tank.urdf)。尺寸单位为米，`world` 原点位于箱体底面中心，Z 轴向上；箱体固定，底面位于地表 z=0。按用户要求将原始平放模型绕 X 轴立起 90°，开口朝世界坐标 -Y；当前占位外形尺寸与开孔高度统一见[合同](../../../doc/assembly_contract.md#场景记录与有效性)。2026-10-01 将开孔组件整体提高并向下补足实体箱体，底面仍落地，孔位不重新居中。URDF 不额外创建地面。

在工作空间根目录单独预览（MuJoCo，仅查看几何，不运行动力学）：

```bash
.venv/bin/python tools/view_mjcf.py --tank-only
```

初始视角朝向立面开口，滚轮可缩放。添加 `--check` 可无窗口检查加载。

局部坐标下的建模内容：

| 部位 | 尺寸 |
| --- | --- |
| 箱体 | 外形尺寸见合同；原带孔分片保持尺寸，新增向地面延伸的实体部分 |
| 顶面中央圆台凹槽 | 入口/槽底尺寸见[合同](../../../doc/assembly_contract.md#场景记录与有效性)，2026-09-30 仅加宽外侧入口 |
| 槽底中央油箱口 | 外径 60 mm、内径 50 mm，环体从槽底向上拉伸 3 mm |

凹槽深度用户尚未指定，暂取 **40 mm**，因此在箱体局部坐标中槽底 z=0.360 m，环口端面 z=0.363 m。此值为建模假设，不是实测值。油箱口沿轴线暂以直径 50 mm 的孔贯通箱体，作为内部腔体的简化，不代表真实油箱内部结构或允许插入深度。没有定义 `refueling_pose`。

圆周采用 64 段近似。外观和碰撞均保留凹槽与开口；碰撞由 192 个独立凸网格与 1 个底部延伸 box 组成，避免将整个凹形箱体取凸包而封住开口。箱体未添加标定质量、惯量、摩擦或其他动力学参数，用作固定环境物体。

网格路径相对于 URDF 文件目录；加载器需支持此解析方式。若加载器只接受绝对路径，应将每个 `mesh filename` 按 URDF 所在目录解析为绝对路径。此目录不是 ROS 包。

在工作空间根目录重新生成（仅使用 Python 标准库）：

```bash
python3 tools/build_fuel_tank_urdf.py
```

`tank_opening_center` 标记开孔外表面的圆心（凹槽入口中心），不是凹槽底部。其箱体局部坐标为 `(0, 0, 0.4)` m；立起后的高度引用合同；独立 URDF 中其 Y 坐标为 -0.2 m。坐标轴相对世界方向为 X → +X、Y → +Z、Z → -Y（朝箱体外侧）。MuJoCo 预览将其显示为 site 坐标系，红/绿/蓝分别为 X/Y/Z。

`tank_recess_floor` 和 `tank_filler_top` 分别标记槽底中心与环口顶面中心。新增 `tank_body_center` 表示完整长方体的几何中心；开孔提高后不再位于箱体高度中点。模型已加入临时臂手组合场景，可通过 `.venv/bin/python tools/view_mjcf.py --with-hand` 查看；组合场景对油箱另加了展示平移，位置见[组合说明](../../../doc/mjcf_inspection.md)。

已验证 XML 解析、网格闭合性/凸性、箱体包围尺寸、中心通孔，以及解析网格绝对路径后的 MuJoCo 编译和一次前向计算。未验证插枪、接触操作或真机动作。
