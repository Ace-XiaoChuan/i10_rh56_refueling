# 自动选择拇指锚点

`tools/run_thumb_anchor.py` 从当前 SpaHybGen 预测和握梁定位选点，复用相对握梁的手部预型，求可行摆放，再验证拇指先接触、四指闭合和短时对握。现在是独立的离线/接触仿真入口，尚未接入机械臂执行。

在工作区根目录运行：

```bash
.venv/bin/python tools/run_thumb_anchor.py \
  --config config/thumb_anchor_trial.json \
  --output-dir tools/artifacts/my_thumb_anchor_run
.venv/bin/python tools/verify_thumb_anchor.py tools/artifacts/my_thumb_anchor_run
```

输出目录必须是新目录。打开其中的 `index.html` 可以切换几何末态、拇指接触和实际闭合状态；`result.json` 保存四指展开受阻、闭合指令与实际运动、侧面接触和端角接触。几何预型可用 `--plan-only` 单独生成。

已完成[同一观测八组锚点比较](../tools/artifacts/cap_thumb_anchor_batch_20261113_001/README.md)，[汇总HTML](../tools/artifacts/cap_thumb_anchor_batch_20261113_001/index.html)可逐组切换实际积分状态。固定输入和参数后，8组中5组形成持续侧面对握，3组四指闭合后仍未形成对握；碰撞与接触过程已独立复核。该比较沿用点云推定坐标与经确认的双侧补全；从新PCD自动估计位姿的衔接另用已知几何样本检查，现场定位精度尚未评价。[此前单锚点结果](../tools/artifacts/cap_auto_thumb_anchor_20261113_003/README.md)保留。

## 换成新观测

配置中的 `run_dir` 指向同次观测的 `contacts.json`、`contacts.npz`、`volume.json`、`network_volume.npz`、`geometry_1mm.npz` 所在目录。入口检查预测、体素、完整点云的上游摘要和参考系，复用已完成的网络推理，不重跑整手 SpaHybGen 优化。

握梁定位有三种输入，配置中只能选一种：

| 配置字段 | 程序执行的工作 | 输入前提 |
| --- | --- | --- |
| `confirmed_geometry` | 读取点云推定的握梁坐标与经用户确认的双侧补全 | 默认配置沿用当前已确认几何，须与网络占据一致 |
| `grip_estimate` | 读取 `estimate_cap_geometry.py` 的相机系顶面定位结果 | 结果须通过几何检查；`pose_index` 默认0，可指定另一180°候选 |
| `cap_cloud` | 从整盖PCD自动拟合盖面、握梁长轴和顶面参考点 | 点云已分离出整盖、具有足够外轮廓和高度分层；`cap_cloud_unit` 必须是 `m` 或 `mm` |

后两种输入须属于网络 `camera_from_volume` 对应的同次相机观测，并在配置中用 `estimate_network_sha256` 显式绑定当前 `network_volume.npz`。可用 `sha256sum` 读取摘要。该绑定记录输入配对，不代替相机标定和现场定位精度验证。定位不成立就返回失败，不套用旧位置。两侧尺寸沿用 `grip_shape` 已知几何，不能称为相机测出了被遮挡侧面。整盖分割、采集及网络前向仍使用现有独立入口。

这里的“人工确认”指用户确认握梁两侧存在实体，可以使用补出的侧面；握梁坐标沿用既有点云推定参考，没有新增实物精度标定。锚点选择与手姿调整由程序完成。

`template_reference` 是离线保存的初始手部预型。程序先换成握梁相对坐标，再随当前定位变换；保留模板不意味着把旧世界坐标用到新场景。

## 关键计算

自动选点在 `src/fuel_cap_task/thumb_anchor.py:rank_anchors`。用预型中四指相对拇指的长轴分布计算锚点应靠哪一端，兼顾浅侧面位置、梁外超出量和原网络分数；最多保留3个相距至少4mm的候选。只要求至少另一指对握，四指全部容纳不作为硬条件。没有历史候选编号或视图左右规则。

拇指的当前手部FK点为 `p`，锚点外侧预放点为 `a`，根旋转为 `R` 时：

```python
# 输入：手部FK点p、当前握梁上的预放点a；单位米。
# 输出：手根平移t，使拇指材料点在几何求解中保持位置。
t = a - R @ p
```

每个候选最多24步局部修正，保留六驱动/十二关节耦合、完整场景、自碰和0.1mm容差。几何预放留1.3mm外侧间隙。四指分别沿限位方向检查展开路径采样，从可行展开预型开始物理闭合，不能把初始距离远当作不可达。展开只检查有限路径采样，不证明连续轨迹安全或其他展开路径不可行。

`ContactSequence` 依据同刻接触反馈推进：`seek_thumb → close_fingers → hold → done`。拇指确认前四指保持；任一接触阶段丢失必要接触、超时或碰撞便失败停止；找到可行几何后本轮只做一次接触试验。形成对握后保持当前位置指令，连续承力至少0.2秒即可。小指接触端角单独显示，不计入侧面对握。

## 当前验证范围

接触阶段用 `ctrl/mj_step` 积分，初始关节只设置一次，没有拇指与握梁焊接。完整点云逐检查点复核，另用保存控制时序重放真实十二关节，并独立检查全部点。HTML仅展示场景抽样和保存状态，力值来自积分中的接触求解。

本入口的接触反馈由仿真提供，保持阶段是位置指令保持。真机仍需要安装/标定复核、右臂坐标与整臂IK、MTC无接触接近路径，以及已核实的接触反馈和柔顺/力控制适配。`reference_from_hand` 保留网络参考系含义；当前默认是左臂基座，不能直接发给右臂。所有结果保留 `motion_target_valid=false`。

仿真假设沿用当前小试：固定握梁、零重力、摩擦 `[1, .005, .001]`、六驱动限力矩±1Nm、位置伺服增益300。力值尚未标定；这次结果用于验证选点和接触流程，不作为真实抓持承载数值。
