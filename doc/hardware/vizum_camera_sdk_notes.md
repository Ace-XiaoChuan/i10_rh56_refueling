## 回公司后的最小验证步骤

1. 按设备说明确认供电、网线和网络配置，记录当前相机 IP；不要猜测供电规格或直接改写设备配置。
2. 先读取设备型号、序列号、固件、瞳距和 RGB 能力，确认 SDK 是否支持此设备；有疑问时将结果交厂家核对。
3. 完成一次静态扫描，保存原始图像、点云和标定信息。核对点云单位、坐标轴、无效值、图像与点云对应关系、采集耗时及时间信息。
4. 对实际盖体和握梁采集少量重复观测，检查凹腔遮挡、反光造成的缺点、边缘质量和位置重复性，再决定安装视角及感知实现。

此阶段先验证“能否获得可用的图像和三维数据”，暂不训练网络或接入机械臂控制。SDK 尚未复制为项目依赖，也未安装或修改硬件；后续设备检查结果统一补入合同。
