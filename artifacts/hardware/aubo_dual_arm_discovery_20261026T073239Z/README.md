## 保存文件

- `network_scan.json`：扫描时刻、网段、端口和逐地址 TCP 连接结果。只表示该次两个端口的可达性，不是完整网络设备清单。
- `controller_queries.json`：两次现有 SDK 只读探针的开始/结束 UTC、退出码与原始输出。
- `provenance.json`：使用的工具路径、摘要、归属依据和未取得的参数。
- `sha256_manifest.json`：上述文件及本说明的 SHA-256。
