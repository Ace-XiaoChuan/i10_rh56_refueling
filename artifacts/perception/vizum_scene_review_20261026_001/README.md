## 覆盖范围需要怎样判断

这里完整保留的是这次扫描返回的数据，尚未确认油箱口、凹槽及门板的覆盖是否足够用于避障。单视角只能记录当时可见并成功测量的表面；远处背景点和较大的包围盒不能证明关键区域没有遗漏，也不能将缺点区域视为空闲空间。

先在“原始扫描”定位目标，再切到“盖体周围窗口”，对照现场检查开口、门板以及手部接近区域。窗口边界记录在 `coverage.json`，窗口仅控制查看范围，不代表新增采集。若关键表面缺失，需要补采或用已核对的几何补充。

`validation.json` 记录实际数据检查：网页各点坐标与原始行号逐一对应，全量视图包含每个原始点恰好一次，PCD 副本摘要一致，无外部脚本或样式表依赖。浏览器交互未在本机做自动化测试。生成源码及所复用的查看页、读取器保存在 `source_snapshot/`。

本次只处理已有文件，没有连接设备或触发新扫描。
