# 当前实测点云的两个候选抓取位

已补齐 0° 和 180° 两个方向的 RH56 手根抓取位。两个方向使用同一份实测点云盖体定位、同一固定手盖关系和同一手指接近预型；本次没有增加沿盖轴外退的预抓取距离。

先打开 [两方向查看页](index.html)或[对比图](comparison.png)。完整矩阵和四元数见 [grasp_candidates.json](grasp_candidates.json)。JSON 长度为米、四元数为 XYZW；PCD/PLY 导出为相机系毫米坐标。

| 方向 | 手根抓取位置，相机系 XYZ（mm） | 独立输出目录 |
| --- | --- | --- |
| 0° | `[99.567281, -30.428056, 474.078368]` | `direction_000/` |
| 180° | `[91.966640, 121.741832, 503.853444]` | `direction_180/` |

每个方向目录包含：

- `cap_cloud.pcd`：同一份实测整盖点云，文件字节与几何输入导出一致。
- `rh56_fixed_grasp.ply`：处在候选抓取位置的 RH56 网格。
- `overlay.json`：相机系及左臂基座系手根位姿、手指参数和来源。
- `hand_only.xml`：派生的独立 RH56 手模型，不含虚拟油箱、油箱盖、机械臂、传感器或地面。
- `preview.png`、`overview.png`、`grip_detail.png`：固定取景下的叠加图。

Windows CloudCompare 中同时打开同一方向的 `cap_cloud.pcd` 与 `rh56_fixed_grasp.ply` 即可旋转查看，无需额外配准。两方向的手网格若同时打开，需要手动切换可见性以免互相遮挡。

## 使用的输入

- 当前几何：`artifacts/perception/cap_observation_20261026_002/geometry/result.json`，整盖 5,742 点。
- 原始观测：`artifacts/hardware/vizum_i10_capture_20261026T055151Z/observation.json`，完整场景 268,852 点。
- 固定抓姿：`config/fixed_grasp.json`。局部手根位置、姿态和六通道均保持原值。

盖体位置和朝向来自实测点云。参考中心继续使用已记录的握梁顶面沿负盖轴回退 8.5 mm 的模型高度关系。MuJoCo 只负责独立 RH56 手模型的前向运动学、网格提取和静态渲染，不读取占位盖体位姿来生成候选，不推进物理时间。

固定抓姿的历史来源 XML 仍保留摘要核对；只从其中提取手部模型，并将其保存为 `hand_only.xml`。旧版已经保存的 0° 结果未被覆盖；新 0° 手根位姿与旧记录完全一致，网格差异在数值舍入范围内。

## 验证结果

`tests/test_cap_hand_overlay.py` 实际运行 12 项通过，覆盖手根变换、独立手与原手几何一致、绕实测盖轴的 180° 关系、PLY 单位、网格索引和不推进动力学。

本次还用独立 PLY 读取器复核了两方向网格：每方向 44,656 顶点、89,627 三角面；点云文件未改写。180° 网格旋转关系最大坐标残差约 `4.44e-16 m`，旧 0° 手网格最大差约 `2.27e-16 m`。左臂基座目标另经“左基座到盖体 × 固定手盖关系”核对。

详细数值见 [validation.json](validation.json)，实现和候选配置快照在 `source_snapshot/`。本次生成的是两个几何候选，尚未选择执行方向，也未进行碰撞检查、机械臂 IK 或真实抓稳试验；没有连接机器人或触发新相机采集。

重现各方向的命令见 `doc/cap_geometry.md#固定抓姿叠加`。使用新输出目录，保留原始实验记录。
