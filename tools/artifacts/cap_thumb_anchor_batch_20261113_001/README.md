# 同一观测的八组自动拇指锚点测验

使用原 `tools/run_thumb_anchor.py`，在同一份离线观测中预先登记8个不同锚点，再分别求解和闭合。**5组形成持续侧面对握，3组未形成对握**，全部结果保留。[打开汇总HTML](index.html)，点击表格行可查看对应组的实际积分状态和接触力。批次耗时196.7秒，含各组HTML导出；单组20.9～35.3秒。

## “人工确认定位”具体指什么

准确说法是：**点云推定的握梁坐标＋用户确认实体存在后的双侧几何补全**。用户确认了相机没有扫全的两侧确实存在实体；使用既有坐标和尺寸补成梯形侧面。没有新增实物位姿精度标定，也不需要用户逐点指定拇指位置。握梁长轴、顶面参考和朝外方向用于换算坐标与摆放手，逐指朝向或到高分点的距离不作为成功判据。

## 固定输入和预算

- 输入观测：`confirmed_sides_0p1_20261112_002`；完整几何667868点，包括634610实测点与33258确认补全面样本。原SpaHybGen预测和分数只读，新增网络前向为0。
- 先复用原 `rank_anchors` 排序，每次排除已选锚点4mm邻域；8点在首次求解前保存在 [selection.json](selection.json)。选择时使用分数副本做邻域排除，保存和求解使用原分数，没有人工指定格号。
- 每组调用同一新入口，重新建立手和物理模型，固定参考预型、碰撞条件、最多24步几何调整与一次接触闭合。批次夹具只替换本组预先登记的锚点列表，不修改求解、接触或物理流程；没有按结果调参、追加锚点或重试。
- 成功要求拇指先接触，随后至少一根其他手指在相反侧面承力并持续至少0.2秒；端角单列。碰撞容差保持0.1mm。
- 握梁与手根固定，没有手梁焊接。手指仅初始化一次qpos，随后经ctrl/mj_step积分。沿用摩擦系数 `[1,0.005,0.001]`、位置增益300、执行器力矩范围±1Nm、零重力；这些参数未经实物标定。固定支撑承担合力与力矩，当前结果评价固定梁局部对握，不能据此确定旋拧扭矩或持盖能力。

原代码、输入与模型的摘要在 [manifest.json](manifest.json)，实现副本与原路径对应关系见 `source_snapshots.json`。完整路径、坐标和分数也保存在每组 `manifest.json`、`anchors.json` 与 `result.json`。默认参考系来自当前观测的 `left_base`，本批没有生成可执行右臂目标。

## 复核和查看

[verification.json](verification.json)记录独立复核结果：8组均精确重放全部控制过程，保存检查点的最大关节误差均为0，末态各指接触力一致；400个实际状态检查点均通过原几何检查。每组另在拇指确认、首次对握（如有）及末态，使用完整667868点直接检查环境侵入和自碰，均无超过0.1mm容差的侵入。5个成功样本连续对握时长为0.200～0.225秒。

HTML包含36个保存状态，数据通过Plotly schema检查，8个表格入口及全部帧切换通过V8中的DOM/Plotly桩检查。`report_checks.json` 和 `ui_checks.json`保存检查结果；未在真实浏览器中完成WebGL渲染检查。查看页来源文字在汇总层统一澄清，原结果、轨迹和求解代码不改写。
