# 拇指换端后的单点小试

**按右手四指排列方向把拇指锚点换到握梁长轴另一端后，已经在固定握梁上形成拇指与中指的承力对握，保持0.20s。**

## 发现和修正

上一小试锚点X=-18.10mm，但中指、无名指、小指指面样本分别在约X=-31.43/-45.10/-65.10mm，超出握梁±30mm长轴范围。选“靠端”时没有核对右手的手指排列，是那次选点的问题。相机视图的左右不能代替这项实体排列检查。

本次保留原手根参考旋转、六驱动预型、四指可选目标和原0.1mm几何容差，只将同一侧面的拇指目标换到长轴另一端的一个原SpaHybGen高分格`[59,89,98]`，原分数0.459913。其侧面投影为`[+22.55,+8.58,-1.41] mm`。候选长轴位置和高度都由该真实网络格决定，不伪造镜像候选或分数；因此这是换端的可行性验证，不是严格只改变X坐标的因果对照。

换端后的几何末态，中指、无名指、小指样本长轴位置约为+10/-6/-26mm，已进入梁长范围；这只说明长轴空间改善，并未证明三指都能接触。无名指和小指仍处于20mm局部吸引范围外，本轮允许不参与。

## 闭合和受力

原软修复在第23步停在0.1mm容差外约36nm，原因是轻微追点项与边界修复竞争。预算内第24步只用既有间隙约束做最小位移投影，消除这点数值残差，没有放宽容差。该收尾步骤与原23步结果分别保存，原实验不覆盖。

无超差预型通过后仅运行一次固定握梁闭合。0.675s形成拇指与对侧中指承力，冻结当时闭合指令并保持至0.875s。

| 手指 | 末态法向力 | 实际接触点X、Y、Z / mm |
| --- | ---: | --- |
| 拇指 | 8.3731 N | +23.92、+8.50、约0.00 |
| 中指 | 4.1451 N | +10.31、-9.14、-10.96 |
| 食指、无名指、小指 | 无承力接触 | 允许不参与 |

无名指和小指本轮没有参与，并非因侵入被拒绝：它们沿用参考手型中的收拢姿态，当前指面距对侧目标约60.36/54.17mm，超过20mm局部吸引范围后，目标梯度为零，且后续预张开和闭合增量也被同一个`active`条件跳过，两路闭合目标与初始指令完全相同。因此本轮没有真正尝试这两指充分张开后的接触可达性。将“当前距离远”用于提前跳过，不能替代用户要求的“先尝试，够不到才放弃”；后续若验证四指潜力，需纠正这项筛选方式。逐项证据见[参与条件诊断](participation_diagnosis.json)。

完整手指合力为`[-0.00410,-3.97679,-2.30718] N`，关于握梁顶面中心的合力矩为`[+0.03002,+0.05187,-0.15138] Nm`，固定机构承担相反的力与力矩。这是固定握梁上的接触结果，尚未验证可用旋拧力矩或脱离后的持盖。

## 验证和范围

- 一个拇指锚点，24步几何更新，1750次物理积分，35个闭合检查点；没有新网络推理或硬件动作。
- 原始输入、旧结果和27项来源摘要一致；拇指和四指目标均保留原网络分数。
- 几何求解期间固定的是带1.3mm外侧间隙的拇指预型指面点；闭合时靠实际六驱动、原十二关节耦合和接触摩擦，没有手盖黏接。握梁固定体无自由度。
- 所有35个闭合检查点都满足原0.1mm场景与自碰条件；独立逐点检查再次复核首次对握及末态的全部667868点，均无超差侵入、自碰为零。未证明检查点间的连续无碰撞。
- 同一控制时序精确重放后，35个关节检查点最大误差为0，末态接触力复现一致。

接触模型沿用上一小试的凸棱柱握梁、零重力、摩擦`[1,0.005,0.001]`、伺服增益300和每驱动±1Nm限力，均未标定；拇指弯曲末态达到假定的1Nm上限。受力数值属于仿真，`physical_grasp_verified`和`motion_target_valid`继续为false。
