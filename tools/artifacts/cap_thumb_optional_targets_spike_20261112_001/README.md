## 试了什么

只复用上一小试的靠左端原网络格`[87,61,88]`，原分数0.799100，投影到确认侧面的位置为`[-18.10,+8.81,-5.27] mm`，握梁两端在X=±30mm。未增加拇指候选、网络推理或硬件动作。

求解时拇指采用同一个真实指面采样点，消去手根平移，允许整手绕该点旋转和六驱动调整。预型在表面外留1.3mm间隙；固定的是这个带间隙的指面位置，尚未验证物理拇指能在此贴住。所有已保存几何状态的该点位置误差均为数值精度内的零。

对侧原高分格中有203格处于握梁长60mm、高17mm的侧面范围，原分数保留，坐标投影到人工确认侧面后作为目标集合。四指分别在既有指面样本与目标集合间选择最近配对。20mm之外吸引残差饱和、梯度为零，允许远处手指不参与；这是局部搜索的预算设置，**没有证明这些手指在整个关节范围内不可达**。没有逐指朝向项，也没有要求四指全接触。

最多24步局部求解，连续3步没有接受更新便提前停止。求解阶段继续采用完整667868点、原十二关节耦合及0.1mm侵入容差。只有无侵入预型才允许进入一次固定握梁闭合，接触成功仍应由真实驱动积分和持续对握受力判断。

## 实际结果

本次求解约30.02s，尝试5步、接受2步，随后连续3步未能改善放置侵入而提前结束，未用满24步预算。

- 食指和中指参与了对侧网络点引导，无名指和小指处于局部吸引范围之外，未被强行拉向目标。
- 整手仍有实测周边结构侵入。独立逐点检查发现43个超差环境点，其中拇指中节11个、拇指末节1个、中指中节31个；目标点无超差、自碰为零。
- 最深实体内侵入为1.26869mm，比0.1mm容差超出1.16869mm。没有把这组姿态当成可闭合初态。
- 没有物理积分、没有受力结论；上次中部锚点的8.37/8.79N属于旧姿态，不能移用到这次靠端摆放。

当前只验证了“单锚点保持、四指可放弃的网络目标引导”能构成并执行一次局部几何求解；靠端对握本身尚未验证通过。后续若研究这个阻挡，应区分初始整手摆放受限与抓握思路不可行。
