## 实现与复核

[fit_reference.py](fit_reference.py)将保存的手根相对位姿放到当前握梁参考，固定三个真实显示三角面样本及对应侧面目标，用原约束最小二乘做小范围修正。第一次完整试探的假设面超差0.0032mm而被拒绝，半步通过完整几何检查，并达到三指标准，随即停止。没有重新训练、网络前向、物理积分或设备访问。

历史接触终态来自动力学记录，十二关节略有耦合偏差。使用有界最小二乘明确换成合法六驱动，完整关节最大变化0.00068363rad（0.03917°），再进行本组修正。当前握梁矩阵的4.1e-8正交误差也经刚体旋转归一化，原矩阵与变动保留在结果中。当前握梁摆放由点云推定，未新增人工确认。

[verify_reference.py](verify_reference.py)用原独立几何检查器、不用优化器的KD广相或Jacobian，重算预张开、闭合参考和最终三种构型的完整点云、自碰、全部假设样本及逐指三角面/FK；45项来源摘要通过。页面真实JS执行了16次控件回调，核对三对彩点、构型切换及预张开碰撞提示。[复核结果](verification.json)通过；[独立审阅](review.md)无Critical/Important问题。

页面使用Plotly三维显示，未进行真实浏览器/WebGL检查。静态图已实际查看，使用全部原显示网格三角面作Matplotlib Agg投影，彩点覆盖其上方便识别；本会话EGL设备和X11不可用，未将软件投影称为MuJoCo渲染。[渲染记录](rendering.json)保存具体后端。

复现：在项目`.venv`中依次运行本目录`fit_reference.py`、`render_reference.py`、`verify_reference.py`。查看已有结果不需要重跑求解。
