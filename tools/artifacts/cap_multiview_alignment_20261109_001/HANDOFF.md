### “人工确认握梁定位”的准确含义

此前说法不够准确，已向用户澄清：**沿用点云推定的握梁坐标，再采用用户确认实体存在后的双侧几何补全。** 用户确认了两侧确实有实体，相机因视角未扫全；现按已有参考与尺寸补成梯形侧面。握梁位姿没有新增实物精度标定，补面也不等于相机测出了遮挡区域。拇指锚点由程序自动选择，无需人工逐点指定。

当前补全几何为长60mm、高17mm、顶宽17mm、底宽19mm。确认侧面及其原网络分数来源见[双侧确认](../cap_confirmed_sides_20261112_001/README.md)；`confirmed_geometry.npz` 内 `volume_from_manual` 是旧字段名，不能据此声称位姿经过精确人工测量。

### 新流程已落地的部分

1. 从同次观测读取SpaHybGen原分数、网络体积、完整场景与握梁位姿；默认复用当前确认几何。还支持相机系 `grip_estimate`，或从已分离的整盖 `cap_cloud` PCD估计握梁；相机输入须绑定同次网络摘要，并明确PCD的m/mm单位。新PCD衔接已用已知几何样本检查单位与坐标变换，现场定位精度未评价。
2. 根据模板中右手四指相对拇指的长轴排列，计算锚点应靠哪一端，避免只看视图左右而抓反。原模板先表达为握梁相对位姿，再随本次定位变换。原排序器保留至少4mm空间分离，默认最多3个锚点。
3. 几何预型将真实FK的拇指材料点固定在锚点外侧1.3mm处，通过 `t = anchor - R @ thumb_fk` 保持位置，允许根旋转和六驱动调整；每点最多24步，完整碰撞不放宽。四指可向近处对侧候选靠近，这只是局部求解引导，不是最终接触判据。
4. 四指均沿实际限位检查展开路径采样，再从可行预型执行物理闭合，**不再用20mm当前距离取消某指参与**。接触阶段只初始化一次qpos，之后用ctrl/mj_step：`seek_thumb → close_fingers → hold → done`。拇指先确认接触，四指随后闭合；首次形成侧面对握便保持当前位置指令，连续承力至少0.2秒。端角接触单列，不算侧面对握；失去必要接触、超时或碰撞即失败停止。

主入口一次运行在找到可行几何后只做一次接触试验，即使接触失败也不自动换点重试。默认最多3点是寻找可行预型的预算；本批八组是明确授权的离线比较，每组独立建立模型、指定一个预先登记的程序选点，使用原入口的求解和接触流程。

## 三种容易混淆的数据与检查

1. **实测点及稀疏表面体素**：原始SDK点云经过既定过滤，保留原点号；按点命中生成1 mm占据格。未命中不表示空闲。`geometry_1mm.npz`同时保存稀疏格与原始观测点，格子主要用于展示，独立几何筛选实际使用其中的观测点。
2. **SpaHybGen深度雕刻网格**：`VoxelVolume`调用Open3D，先创建全满体积，再按深度删除部分格子。当前网络局部范围160³、边长0.16 m，间距1 mm；几何观测范围另为0.4 m。有效深度表面后方通常保留为1，但无效深度和视野外也可能被删成0。因此0/1都不能直接解释为可靠的空闲/实测占据三态。雕刻只删除，后续视角不会自动恢复先前误删的格子。
3. **独立几何筛选**：`tools/check_saved_cap_grasp_geometry.py`提取RH56碰撞子树，用原始观测点检查目标/环境表面是否进入手部碰撞实体，并检查自碰、方向、至少两活动指邻近目标。穿透容差0.1 mm、近目标距离5 mm。没有点支持的未知区域，目前未据此阻止手进入。

已有`observed_free_grid`单独标记有效深度支持的空闲格，但它尚未成为候选优化或最终未知区域筛选的约束。不要把它的存在误当成已接通三态避障。

### 已厘清：网络、优化器、接触引导和5mm筛选

- 网络是固定预训练3D U-Net，输出接触得分、方向和中心等。优化器用PyTorch可微运动学和Adam，更新手根位置、朝向、六驱动角；反向传播不等于训练网络。

- `near_target_distance_m=0.005`和`minimum_near_fingers=2`是生成后独立筛选条件，原来不是会主动拉近手指的损失项。它只表示至少两活动指的指面采样点距实测目标≤5mm，不表示已实际接触或稳定夹持。

- 1mm已用于格索引与米制坐标转换；本轮未发现仍按5mm换算的直接错误。QH仍沿用原邻差及0.01m代理位移，FQH阈值来自随机指面点对平均距离/10。物理感受野、预测分布、采样和优化尺度适配仍需研究，不能归纳为“改一个权重就必然解决”。

### 下一步讨论：让指肚“粘”在网络高分点上（尚未实施）

用户提出下一步是否应直接解决网络引导手指的问题，希望更直接地让手指贴住高分点。现有代码只选择两指参与软损失，没有逐指固定接触对应；原FQH还随机抽取部分高分焦点，因此当前没有“指定指肚必须到达指定点”的条件。

助手建议研究“固定接触对应＋受约束的运动学求解”：

1. 从现有6个高分点中，为拇指和另一根手指分配位于握梁相对两侧的点；每次求解固定配对，失败后再换点或换配对手指。五指及手根仍可动，不强制三指同时接触。
2. 每根参与接触的手指选一个有效指肚接触位置，经真实运动学调整手根和关节，使该位置满足 `||p_pad(q) - p_feature|| ≤ ε_contact`，并检查指肚朝向。助手建议先以 `ε_contact=0.001m` 验证贴点；这是待落实的方案建议，不是已确认的新运行参数。指肚区域、朝向门槛和具体求解器仍需明确。
3. 最终同时满足贴点、完整实测避障、自碰与驱动限位，才接受该组合。求不出满足条件的姿态则报告失败，不通过放宽环境穿透来换取贴点。单纯增加接触损失权重不能提供必须贴点的条件。
4. 接触位置必须来自真实手模型FK，不能修改显示点坐标来制造贴合。人工侧壁的完整几何及防贯穿问题仍需单独处理；贴到旧高分格本身不证明那里存在真实可承力表面。

这轮尚未实现上述约束或生成新候选，也没有验证当前6个高分点一定能形成运动学可达、无碰撞的对向抓握。接续时优先明确这一方案，再安排独立实验；无需重跑已完成批次来确认已有结论。
